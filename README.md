# 七年级英语AI学习助手

面向人教版 **Go for it! 七年级**的英语学习与薄弱点训练闭环：

> 教材 → 语料 + RAG → 组定级卷 → 语音评测 → 多维画像 → 大模型报告 → 针对性练习 → 练习结果回流，再出一组

三种能力叠在一起：

- **评测**：驰声MCP语音评测, 按题型固定工具链.
- **诊断**：4 维口语画像 + 语法画像 + **音素级对齐** (错读 / 漏读 / 多读 / 发音不到位).
- **推荐**：从教材语料里检索候选, 由大模型在候选内挑题并写针对性理由; 薄弱知识点题量不足时按知识点补题.

---

## 一、前期准备
- 机器应安装ffmpeg, 以支持录音转换
- python 3.12
- https://api-account.cloud.chivox.com/zh  # 驰声MCP服务(如需少量体验, 可联系 wx: hppy139)
- LLM api服务

---

## 二、运行说明
- pip install -r requirements.txt
- cp .env.example .env  # 填写APP_KEY
- pkill -f "uvicorn app.main:app"  # 关闭服务
- python -m uvicorn app.main:app --host 127.0.0.1 --port 8080  # 开启服务
- 然后浏览器进网页 http://127.0.0.1:8080/
- 体验步骤(可参考examples/):
  - (1) "定级测评"页面, 点击"开始定级".
  - (2) 逐题作答, 完成后点击"生成报告".
  - (3) 点击"去练习", 即进入"习题推荐"页面.
  - (4) 答题完成, 点击"本轮完成，再来一组", 即可推荐下一轮习题.

---

## 三、不足
- 语料由《【人教版】七年级上册英语电子课本-社学整理》.pdf解析, 可能存在不合理情况:
  - 单独单词拼接成不合理句子
  - 单句拼接成不合理段落
- RAG暂未实现多模态.
